OPTIONAL RECOVERY PROFILE

Bring sign-in recovery into the plan.

Select Recovery profile in the backup checklist, or use the additional parameter below. It collects available settings, network information, app recovery guidance, and an owner-selected password-manager export.

$ ./dump data /mnt/android-backups/phone-before-reset --recovery-profile

An encrypted archive is created with a passphrase. A readable credentials TXT copy is retained only after explicit confirmation.

Designed with boundaries

  • ✓ Keeps captures and backups local
  • ✓ Requires confirmation for sensitive actions
  • ✓ Uses official app export or transfer flows
  • ✓ Uses known system network records only when root already exists
  • × Does not bypass screen locks, app protections, or private app databases

BEFORE YOU WIPE

Review the manifest. Keep backups private.

Backups can contain personal media, account-related metadata, Wi-Fi identifiers, and exported credentials. Keep them on controlled storage, retain the archive passphrase separately, and use official in-app transfers for authenticators, banking apps, and encrypted private data.
